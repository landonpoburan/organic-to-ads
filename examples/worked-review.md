## Requested expansion: three ad directions

### 1. A worked-example static

**Source learning:** showing where a real task fits makes the planner's use tangible. **Hypothesis:** one clear placed task can communicate that use at a glance. **Angle/concept:** a visible place for the next task. **Format:** static close-up.

**Image:** original list beside Monday's filled box, with a hand indicating the matching task. **Headline:** "Give the next task a place." **Primary text:**

> Start with the list. Choose the first task. Give it a place on the weekly page. This desk planner puts the week on one page so the plan is easy to see. Explore the layout and features on the product page.

**CTA:** Explore the planner. **Proof:** the product layout and task placement, supplied in slides three and four. **Production:** capture a readable product close-up; verify text in the actual image. **Test:** condensed visual explanation versus the full carousel. Format, sequence, and copy change together. **Priority:** lower-effort expansion if a suitable frame is available.

### 2. Question-first process carousel

**Source learning:** the opening question leads into a useful answer. **Hypothesis:** a concrete task question can make the process feel relevant. **Angle/concept:** choosing a place for the first task. **Format:** carousel.

1. Original list and planner: "Which task gets a place first?"
2. Circle "reply to supplier": "Choose one task from the list."
3. Write it in Monday's box: "Give it a place on the weekly page."
4. Place the other tasks later in the week: "See the plan together."
5. Show the completed page: "Explore the weekly desk planner."

**Primary text:**

> A task list is a starting point. Here is one way to use it on a weekly page: choose a task, give it a place, then lay out the rest of the week. See the weekly desk planner's features on the product page.

**CTA:** Explore the planner. **Proof:** a worked page, not a promise of improved productivity. **Production:** reshoot/rearrange the supplied sequence. **Test:** a shorter question-led sequence versus the original. Several elements change, so it is a concept variation. To isolate the hook, change only slide one in a separate version.

### 3. Hands-on demonstration video

**Source learning:** viewers can follow the physical process. **Hypothesis:** motion makes the action easier to understand. **Angle/concept:** watch one list become a weekly page. **Format:** overhead demonstration.

| Beat | Visual | Spoken draft |
|---|---|---|
| Opening | List beside an open planner | "Where does this task fit this week?" |
| First action | Circle "reply to supplier" | "I'll start with this one." |
| Placement | Write that task in Monday's box | "It gets a place here." |
| Rest of the week | Add the remaining tasks to later boxes | "Then I'll put the rest on the weekly page." |
| Proof and close | Hold a readable view of the page | "That's the week on one page. Explore the desk planner's layout and features on the product page." |

**CTA:** Explore the planner. **Production:** an overhead recording of the actual page, legible framing, and a speaker or voiceover. **Test:** a motion-led execution versus the carousel; this changes format and narration together. **Priority:** after the lower-effort asset, unless recording is already available.

All drafts use supplied product-use facts; none claims completed tasks or customer results. The static condenses the mechanism, the carousel reframes the process around a question, and the video demonstrates physical action. They are distinct execution hypotheses, not three newly proven angles.
