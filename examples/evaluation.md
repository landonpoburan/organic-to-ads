## Review rubric

Score each dimension 0 (missing/wrong), 1 (partial), or 2 (clear and usable). This is an editorial review aid, not a predicted performance score.

| Dimension | What to inspect |
|---|---|
| Decision usefulness | Candidate and next action appear first; reuse/edit/re-record/skip is explicit; no recommendation quota. |
| Priority and readiness | Organic strength and pursuit priority stay distinct from per-use readiness. Missing CTA does not block viewing/awareness use; direct-response adaptation names the smallest change. Unfinished asset access is not proof of poor fit. |
| Evidence integrity | Comparable baseline and caveats; accurate source details; no fake inspection, conversion proof, or statistical certainty. |
| Mechanism | Specific source evidence and a useful comparator; observations separated from hypotheses. |
| Commercial fit | Goal, proof, offer bridge, and real next step determine the verdict separately from reach. |
| Expansion quality | Distinct hypotheses; preserved source learning; requested copy/scripts actually delivered; natural voice. |
| Test practicality | Effort/material, constants, changed variables, main outcome, and supplied decision constraints are explicit. |

Any fabricated evidence, credential disclosure, invented destination presented as confirmed, or unauthorized platform action fails the case regardless of score. Record the prompt, host/model, inputs, output, and reviewer observations privately. Revise the skill only for observed failures, then rerun the affected case.

The included worked review is an authored reference output checked against the fixture. It is not evidence that every host or model passed these cases. Test with your intended assistant before relying on recurring recommendations.

## Validate complete real runs privately

For a real run, retain the prompt/business context, raw scan and analysis, source media/transcript evidence map, final report, and review notes outside the public package. Record whether each shortlisted candidate's complete spoken/written source and key visuals were reviewed; a few sampled frames do not make a completed review.

Check that the report's priority/readiness distinction changes an actual decision, its claimed mechanism is traceable to the asset, its proposed edit or re-recording preserves a supported learning, and its first test has an outcome matching the chosen ad use, and a destination where relevant. Independently recalculate important baseline values from the raw posts. Note remaining access, proof, and commercial-context gaps explicitly.

Compare the result with the previous output that triggered the change. A manual same-assistant walkthrough is useful but must be labeled as such. Do not report an independent model evaluation or general success rate without actually running it. Re-run affected cases after an observed failure; no credential sharing, public client fixture, live ad write, or new schedule is necessary to evaluate recommendations.
